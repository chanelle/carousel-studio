# Carousel Studio

A low-spoon Instagram carousel builder. It encodes 8 reusable format anatomies —
pick a format, set your frames, type copy, place photos, and download print-clean
1080×1350 PNGs, individually or as a ZIP.

Built for one person's real workflow; designed to be reusable by anyone.

## The 8 formats

- **Q&A Quickfire** — rapid questions, rapid answers
- **PSA** — say the thing clearly
- **Day in the Life** — process over polish
- **Show and Tell** — look at this, here's why it matters
- **ATTENTION!** — stop the scroll
- **Teardown** — take it apart, show the insides
- **Field Note** — capped at 3 frames by design; the low-spoon cadence-saver
- **Hot Take** — one sharp opinion, defended

## The flow (4 moves)

1. Pick a format
2. Set frame count (3–10, within each format's rules)
3. Type copy, place photos, tune layout / color / crop per frame
4. Download PNGs or a ZIP

## Design

- Essayist identity: Noto Serif Display / Noto Sans / Liberation Mono
- WCAG 2.2 AA contrast throughout
- Exports at 1080×1350 (4:5)

## Privacy

Everything runs locally in your browser. No accounts, no uploads, no tracking,
no server. Your photos never leave your device.
